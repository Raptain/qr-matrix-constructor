\# QR/Matrix Code Constructor



Генератор QR-кодов, Data Matrix, Aztec и PDF417 с веб-интерфейсом.



\## Деплой на Render



\[!\[Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)



\## Локальный запуск



```bash

git clone https://github.com/Raptain/qr-matrix-constructor.git

cd qr-matrix-constructor

python -m venv venv

source venv/bin/activate  # или .\\venv\\Scripts\\Activate на Windows

pip install -r requirements.txt

python app.py
